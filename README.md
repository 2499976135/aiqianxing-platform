# 为爱黔行公益项目协作平台

面向「贵州省为爱黔行公益服务中心」的响应式公益项目数字化协作网页平台 Demo（免下载安装，同时适配 PC 与手机浏览器）。

围绕「项目点位」这一唯一核心资产底座，打通 **合作方透明进展反馈 / 待冠名点位自助认领 / 乡村老师极简打卡 / 机构统一管理** 四大环节。

> 当前为前端 Demo 版本：数据通过 `localStorage` 持久化，无后端依赖，可直接运行体验完整业务闭环。

## 🖼 静态原型 v2（满版橙色 · 实拍素材）
单文件页面：`public/prototype-v2.html`，本地启动后打开 `http://localhost:5173/prototype-v2.html`（线上即 `https://<域名>/prototype-v2.html`）。
- 以真实项目照片做满版首屏，主色为机构橙 `#E8752B`；三个端口可在页脚切换，也支持直达 `#/teacher`、`#/admin`。
- 覆盖：合作方进展反馈 + 待认领目录 + 失效链接、教师双机打卡、机构后台（概览/点位/发布/合作方链接/审核/超期提醒）。
- 页面内部图片全部内嵌，单文件即可直接发给机构或客户预览，不依赖构建产物。


## ✨ 四大核心端口

| 端口 | 路由 | 核心能力 |
| --- | --- | --- |
| ① 机构统一管理后台 | `/admin` | 点位建档上下架、公共素材中心、进展动态发布、专属链接生命周期管理、认领与打卡双审核工作台 |
| ② 合作方专属进展反馈页 | `/p/:token` | 免登录私密访问、项目概况 + 倒序进展时间线、长短期差异化呈现、防下载预览 |
| ③ 待冠名点位认领目录 | `/claim` | 公开筛选、在线意向提交、点位即时锁定防撞单、人工确权后自动下架 |
| ④ 乡村老师手机打卡端 | `/t/:schoolCode` | 学校自动识别、大字一屏表单、弱网草稿暂存、审核状态透明可查 |

Demo 总览入口：`/`（含数据统计与一键重置）

## 🔄 核心业务闭环

```
机构建档 → 公开推介 → 合作方自助认领（实时锁点）→ 机构人工审核确权
   ↓
生成专属链接 → 合作方免登录查看进展 ← 机构发布进展动态
   ↓
老师到校打卡 → 机构审核 → 过审素材汇入公共素材池 → 对外引用
```

点位生命周期状态机：`待认领 → 认领审核中 → 进行中 → 已结项`

## 🧩 产品守则落地

- **专属凭证严格隔离**：访问凭证为 24 位随机不可枚举 token，服务端校验归属映射，失效统一返回引导页
- **儿童肖像优先保护**：对外页面禁用右键另存、拖拽保存与原生下载入口，儿童肖像素材强制标记并锁定
- **关键节点人工把关**：认领通过需二次确认，认领与打卡驳回必填原因，全部操作留痕
- **长短期全周期陪伴**：长期点位支持 3 年运维持续追加进展，短期点位验收即结项归档，结项后停止新打卡

## 🧭 体验路径建议

1. 打开 `/` 查看 Demo 总览与数据统计
2. 进入 `/admin` 工作台，在「点位管理」新建一个点位
3. 到 `/claim` 以合作方身份提交认领意向（该点位实时锁定）
4. 回到 `/admin/reviews` 审核通过（会绑定合作方并自动生成专属链接）
5. 在 `/admin/links` 复制专属链接，打开 `/p/:token` 查看合作方视角
6. 手机尺寸打开 `/t/SCH001` 提交一次课堂打卡，再到 `/admin/reviews` 审核
7. 审核通过后素材会出现在 `/admin/materials` 素材中心

> 演示数据可随时在首页「重置 Demo 数据」恢复初始状态。

## 📁 目录结构

```
src/
├── components/
│   ├── ui/            # 基础 UI 组件（button/card/dialog/tabs/select…）
│   └── common/        # 业务公共组件（防下载预览、红点角标、空状态）
├── pages/
│   ├── admin/         # ① 管理后台（工作台/点位/素材/审核/链接）
│   ├── partner/       # ② 合作方专属进展反馈页
│   ├── claim/         # ③ 待冠名点位认领目录
│   └── teacher/       # ④ 乡村老师打卡端 + 本校记录
├── store/             # Zustand 全局状态与业务动作
├── data/              # Mock 种子数据与文案映射
├── types/             # 领域模型类型定义
└── lib/               # cn() 工具、随机凭证生成
```
